# docs/IDEAS.md — 專案靈感與待討論功能清單

> **規則**：每當開始實作某個「區塊」的新微任務前，Agent 必須先檢查下方對應標籤的項目，並主動詢問開發者是否要納入本次討論或實作。

---

## 待處理想法清單

### [區塊 1 - 瀏覽器 Agent]
- [ ] **多媒體分享支援**：支援解析朋友傳來的貼文分享連結或圖片（將 blob 轉為 Base64 傳給後端）。
- [ ] **自動滾動載入舊訊息**：進入未曾完全同步的聊天室時，模擬平滑向上滾動以載入歷史紀錄。
- [ ] **反爬蟲隨機微延遲**：模擬真人打字時加入更加隨機的停頓（如 50ms ~ 180ms 波動）。

### [區塊 2 - 中繼後端]
- [ ] **AI 智慧摘要通知**：串接本地（Ollama）或雲端 LLM API，當單一聯絡人連續傳超過 5 則長訊息時，自動生成一句話摘要附在 APNs 推播通知裡。
- [ ] **離線排隊優先權**：文字訊息優先發送，多媒體檔案稍後在背景重試。

### [區塊 3 - iOS App]
- [ ] **勿擾白名單模式**：只接收特定幾位重要摯友或聯絡人的推播通知，其餘對話僅靜音顯示未讀數字。
- [ ] **自訂外觀主題**：支援深色 OLED 純黑模式與 VS Code 程式風格主題。
- [ ] **快捷回覆預設常用語句**：在輸入框上方提供可一鍵發送的預設常用句。
