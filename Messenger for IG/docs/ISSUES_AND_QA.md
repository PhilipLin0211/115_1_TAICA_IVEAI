### QA-001：舊 Windows 筆電作為長期開啟讓 Agent 讀取網頁的常駐主機之可行性與注意事項
- **日期**：2026-11-22
- **問題**：舊筆電作為長期開啟讓 Agent 讀取網頁內容但系統是 Windows，是否會影響專案使用的工具或爬蟲技術的做法？
- **結論與原因**：
  1. **完全無負面影響**：Playwright 由微軟官方維護，Python + Playwright 在 Windows 平台上是第一等公民。其網路層封包監聽（CDP / Network Events）與網頁自動化邏輯在 Windows 與 macOS / Linux 完全一致。
  2. **圖形介面優勢**：Windows 原生桌面環境便於進行初次「有頭（Headful）手動登入」，能直觀輸入帳號密碼與 E2EE PIN 碼並保存至 `user_data_dir`。
  3. **需特別注意之 4 個設定**：
     - **電源管理**：必須設定「接通電源時永不休眠」並將「闔上螢幕動作」改為「不進行任何動作」。
     - **Windows Update**：需防範自動重開機，建議搭配 `PM2` 或「Windows 工作排程器」設定開機自動啟動與守護常駐。
     - **路徑跨平台**：Python 程式碼一律採用標準庫 `pathlib.Path`，避免寫死斜線導致跨平台問題。
     - **防火牆與遠端**：若中繼後端也跑在此筆電，需放行 Windows Defender 防火牆對應 Port，或搭配 Tailscale / Cloudflare Tunnel / ngrok 建立手機連線通道。

### QA-002：初次開發 iOS App 是否能免費安裝到自己的 iPhone 實機上？
- **日期**：2026-11-22
- **問題**：沒有做過 iOS 開發，做完之後有辦法在自己的 iPhone 手機上安裝嗎？需要付費嗎？推播通知有限制嗎？
- **結論與原因**：
  1. **完全可以免費安裝到個人實機**：只要有 Mac 電腦（安裝免費的 Xcode），並登入您平時使用的免費 Apple ID，接上傳輸線（或同一 Wi-Fi）即可在 Xcode 點擊「Run」一鍵側載（Sideloading）安裝到您的 iPhone。
  2. **免費 Apple ID 的限制**：
     - **憑證 7 天到期**：免費開發者證書簽發的 App 在 7 天後會失效，屆時只需接上電腦在 Xcode 重新按一次 Run 即可續期。
     - **同一裝置最多 3 個 App**：免費帳號在同一台 iPhone 最多同時安裝 3 個自行簽名側載的 App。
  3. **推播通知（APNs）替代方案**：
     - Apple 官方的 APNs 推播權限要求「付費 Apple Developer 帳號（年費 99 美元）」。
     - 若使用免費 Apple ID，在 App 開啟中或背景短暫停留時，WebSocket 能正常收發訊息；若希望完全鎖屏時收到即時推播，中繼後端可串接免費開源的 **Bark App**（iOS 上極簡推播神器）或 **Telegram Bot** 發送手機通知，點擊直接拉起 PureIG App，無需花費任何年費！
