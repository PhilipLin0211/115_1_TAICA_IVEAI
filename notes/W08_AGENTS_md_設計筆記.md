# W08｜建立自己的 AGENTS.md 與自動化網站架構筆記

## 本週核心觀念：從 Vibe Coding 走向可持續擴充

- **Vibe Coding**：目標是快速把「單一網頁」做出來，每次修改都要重新描述上下文。
- **AGENTS.md 規範開發**：先定義好**設計系統（CSS 變數）**、**資料夾結構**、**資料格式（`data.json`）**與**AI 執行流程**，讓後續新增頁面或內容時能保持完全一致的風格。

## 本站自動化連動機制

1. **檔案總管資料來源**：首頁讀取根目錄的 `data.json`，自動渲染作業、講義與 `notes/` 底下的 `.md` 筆記。
2. **GitHub Actions 自動掃描**：只要把新的 PDF 放進 `PPT/`，或把新的 `.md` 放進 `notes/` 並推上 GitHub，`scripts/build_manifest.py` 就會自動更新 `data.json`。
3. **網頁自訂功能**：可在網頁左側面板直接新增**上課影片連結**、撰寫新筆記或修改專案顯示名稱（`displayName`），再透過上方 **「匯出 data.json」** 覆蓋儲存。
