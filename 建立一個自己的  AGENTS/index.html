⚙️ 二、自動化資料流架構（build_manifest.py + GitHub Actions）
[Step 1 檔案異動] 將新講義放入 PPT/*.pdf，或在 notes/*.md 建立新筆記，或新增作業資料夾。
[Step 2 自動觸發] 檔案推送到 GitHub main 分支，觸發 .github/workflows/update-manifest.yml。
[Step 3 掃描建置] 執行 python3 scripts/build_manifest.py，智慧解析筆記標題、檔案大小與作業中繼檔。
[Step 4 寫入清單] 自動產生最新的 data.json 並自動 Commit / Push 回儲存庫。
[Step 5 靜態呈現] 前端 index.html 透過 fetch('data.json') 取得最新清單，自動更新左側檔案樹與內容！
