# 01. 什麼是 AI Agent？（核心架構定義）

## 一句話白話定義
**AI Agent（自主型語言模型代理人）** 就像一位「不只會給建議、還能自己查資料、按計算機、寫程式並把整件事辦妥的數位特助」。

## 核心直覺與運作機制
- 根據 Lilian Weng 提出的經典架構，一個完整的 AI Agent 由四大模組組成：`Agent = LLM（大腦） + Planning（規劃） + Memory（記憶） + Tool Use（工具）` `[[src-01]]`。
- **LLM 扮演中央處理器（大腦）**：負責理解人類的模糊指令、進行邏輯推理、決定下一步該做什麼，以及整合最終結果 `[[src-01]]`。
- **主動感知與行動閉環**：傳統對話機器人是「你問一句、它答一句」的被動問答機；而 AI Agent 則會針對目標持續執行「思考 $\rightarrow$ 呼叫工具 $\rightarrow$ 觀察結果 $\rightarrow$ 修正策略」，直到任務真正完成為止 `[[src-01, src-02]]`。

## 解決了什麼痛點？（與前代模型對比）
- **痛點（純 LLM 的三大局限）**：傳統 ChatGPT 類模型受限於「訓練資料截止日期（不知道今天新聞）」、「算數與精確邏輯容易出錯」以及「無法直接操作外部軟體（如寄信、查資料庫）」`[[src-01, src-03]]`。
- **解法**：透過賦予 LLM 規劃能力、外部記憶與工具介面，讓模型從「只會紙上談兵的顧問」升級為「能真實與數位世界互動的執行者」`[[src-01, src-04]]`。
