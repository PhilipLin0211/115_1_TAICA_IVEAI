# 03. AI Agent 的記憶架構（短期與長期記憶）

## 一句話白話定義
**Agent 記憶系統** 就像人類同時擁有「腦海裡的暫存便利貼（短期記憶）」與「書櫃裡的龐大檔案夾（長期記憶）」，讓 AI 即使聊了幾個月也不會忘記重要細節。

## 核心直覺與運作機制
- **短期記憶（Short-term Memory）**：直接存放在 LLM 的 **Context Window（上下文視窗）** 中，包含當前的對話紀錄與剛查到的工具結果。優點是讀取極快，缺點是容量有限且每次推論都要重新計算成本 `[[src-01]]`。
- **長期記憶（Long-term Memory）**：將歷史經驗轉成向量（Embeddings）存入外部 **向量資料庫（Vector DB）**，需要時再透過語意檢索（RAG / MIPS）撈回相關片段 `[[src-01]]`。
- **史丹佛記憶流三維評分（Memory Stream）**：在《Generative Agents》研究中，Agent 撈取記憶時不只看語意相關度（Relevance），還會綜合考量 **新近度（Recency）** 與 **事件重要性（Importance）**，並定期把零碎記憶濃縮成高層次的「反思洞見（Reflection）」`[[src-05]]`。

## 解決了什麼痛點？（與前代模型對比）
- **痛點（金魚腦效應）**：傳統 LLM 一旦對話超過 Context Window 上限，最早的指令與關鍵資訊就會被截斷遺忘；開新對話則一切歸零 `[[src-01]]`。
- **解法**：透過「短期視窗 + 外部向量庫 + 定期反思摘要」的分層架構，讓 Agent 具備跨工作階段（Cross-session）的持久記憶與行為一致性 `[[src-01, src-05]]`。
