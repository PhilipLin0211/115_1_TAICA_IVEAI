# 04. 工具使用（Tool Use）與行動介面

## 一句話白話定義
**Tool Use（工具使用）** 就是為原本只有一顆大腦的 AI 裝上「手和腳」——讓它學會自己按計算機、上網查即時資料、執行 Python 程式或呼叫各種軟體 API。

## 核心直覺與運作機制
- **Function Calling / API 串接**：開發者將外部功能（如 `search_web(query)`、`run_python(code)`）包裝成帶有說明書的函數介面；當 LLM 判斷需要外部協助時，會輸出結構化的 JSON 指令請求系統執行，再把結果餵回給 LLM 繼續思考 `[[src-01, src-04]]`。
- **Toolformer 的自我學習**：Meta 的研究證明，語言模型不需要依賴大量人工標註，就能透過自我監督學習（Self-Supervised Learning）自己測試「在句子哪裡插入計算機或搜尋 API 能讓預測更準確」，進而無師自通學會使用工具 `[[src-03]]`。
- **ACI（Agent-Computer Interface）設計原則**：Anthropic 工程團隊指出，工具的描述文字、參數名稱與錯誤提示必須寫得像「給人類看的精緻使用手冊」，明確防呆，才能大幅降低模型傳錯參數的機率 `[[src-04]]`。

## 解決了什麼痛點？（與前代模型對比）
- **痛點**：語言模型本質上是「機率接龍機器」，做多位數乘法容易算錯、問它今天股價會答不出來，也無法主動幫使用者寫入檔案 `[[src-01, src-03]]`。
- **解法**：把「不擅長的事（算數、即時搜尋、資料庫操作）」外包給確定性高的外部程式工具，讓 LLM 專注在最擅長的語意理解與決策調度 `[[src-03, src-04]]`。
